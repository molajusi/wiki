    - 《메가맨 레전즈》: 저장 = 로봇 동료와의 대화. 이 동료가 "주변 메모리 저장 장치(peripheral memory storage device)" 역할을 겸함.
    - 《더 미이라: 디매스터드》(The Mummy Demastered): 보스가 지금까지 찾은 장비 목록을 기록해, 다음 병사가 그 장비를 그대로 물려받음.
    - 《브라마 포스》(Brahma Force): 비디오 로그를 기록하는 제어판이 세이브 포인트 역할도 겸함.

    - .hack 시리즈: 캐릭터가 게임 속에서 실제로 "로그오프"하는 행위로 세이브를 묘사.
  종교적 대조 사례(참고용, 이미 알려진 것): 《캐슬바니아》(천사상/성모상 앞), 《스카이워드 소드》(새 석상 = 여신에게 기도 올리는 행위로 설정).
  비평: Sirlin의 세이브 시스템 분석 — 게임이 플레이어의 게임 밖 삶을 존중해야 한다는 논지, 세이브/체크포인트 분리는 디자인적 이유가 아니라 기술적 이유에서 나온 것이라는 비판.
  (주의: 위 4개 디제틱 사례(메가맨 레전즈/미이라/브라마 포스/GTA)는 검색 엔진의 합성 요약으로 받은 내용이며, 기사 1차 원문을 직접 열람해 문장 단위로 대조하지 않았음 — 추가 검증 필요.)

=== 검색 질의 7: "diegetic save system game design theory non-diegetic justified save point" (WebSearch, standard) ===
- TVTropes, "Justified Save Point": https://www.tvtropes.org/pmwiki/pmwiki.php/Main/JustifiedSavePoint
  정의: 세이브 메커니즘을 게임 세계 내의 합리적 장치(기기·캐릭터·행위)로 설명하는 트로프 전반을 지칭하는 명칭.
- Wayline.io, "Diegetic Interfaces in Game Design": https://www.wayline.io/blog/diegetic-interfaces-game-design
  이론적 틀: 어니스트 애덤스(Ernest Adams)가 저서 《Fundamentals of Game Design》에서 "세이브는 본질적으로 게임 세계 바깥(비-디제틱)에 있으며 몰입을 해친다"고 주장했다고 인용됨. 이에 대한 반론으로, 세이브 시스템을 게임 세계의 일부로 디자인하면 오히려 몰입을 지지할 수 있다는 학생 논문(저자 미상, 서지 불완전)이 언급됨.
  디제틱 세이브의 표준 예시: 《데드 스페이스》 — 주인공이 함선 내에서 실제로 조작하는 세이브 스테이션.
  관련 리서치: 디제틱 인터페이스가 몰입도는 높이지만 체감 사용성(perceived usability)은 낮춘다는 연구 결과 언급(서지 불완전, 재검증 필요).
- Game Developer(舊 Gamasutra), "Save System Design" 시리즈(pt.1~pt.3): 세이브를 "제한된 자원"으로 다루는 설계론. 레지던트 이블의 고정 세이브 스테이션 + 감쇠(decay) 동역학이 "세이브 지점 간격을 벌리면서도 일정한 유연성을 허용"하는 사례로 분석됨(링크: https://www.gamedeveloper.com/design/save-system-design-pt-1 등, 본문 상세는 미열람).
